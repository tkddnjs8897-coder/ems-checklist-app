엑셀 파일을 놓으면 구급일지 PDF가 됩니다

구급일지 값 엑셀이든 월별 오류 엑셀(0/1)이든 종류를 알아서 구분해서 바꿔 드려요.

파일이 없으면 연습용으로 받아서 올려 보세요

어떤 엑셀을 올리나요?
  • 월별 오류 엑셀(0/1) — 구급정보시스템에서 받은 파일(앞 4열 + 항목별 0·1). 1로 표시된 칸이 빨갛게 표시된 구급일지 PDF가 됩니다. 환자 값은 들어 있지 않아 비워 둡니다.
  • 구급일지 값 엑셀 — 시트 이름이 일지값·심뇌혈관·중증외상인 파일. 값이 채워진 구급일지·세부상황표 PDF가 됩니다.
  • 값 엑셀은 시험용 일지 만들기 탭에서 만들 수 있습니다.
